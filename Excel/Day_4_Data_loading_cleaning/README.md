# Day 4: Excel – Data Loading & Data Cleaning

## 📌 Overview
Day 4 focused on learning how to import data into Microsoft Excel from multiple external sources and clean it using the **Power Query Editor**. I also explored database connectivity using ODBC and learned how Excel can connect to different data sources for analysis.

## 📚 Topics Covered

### 1. Loading Data from External Sources
Learned how to connect Excel to different data sources and import data for analysis.

- **Text and CSV Files:** Importing structured data from text and CSV files.
- **Web:** Loading data directly from web sources.
- **SQL Databases:** Connecting Excel to databases such as Microsoft SQL Server and MySQL.
- **Excel Files:** Importing data from other Excel workbooks.
- **ODBC Connection:** Understanding how ODBC enables Excel to connect to supported databases and external data sources.

### 2. Power Query Editor – Data Cleaning
Practiced cleaning and transforming raw data using Power Query Editor.

Key operations covered:

- Removing empty rows.
- Removing empty columns.
- Removing duplicate rows.
- Changing column data types based on the values.
- Renaming columns when required.
- Removing errors from datasets.
- Applying proper column headers.

### 3. Data Preparation Workflow
Understood how Power Query helps prepare raw data before analysis by importing, cleaning, and transforming it into a structured format.

**Workflow:**

`Connect to Data Source → Import Data → Clean with Power Query → Transform Data → Load into Excel`
