Creating a Workbook

A workbook is a collection of worksheets.
Each sheet contains rows and columns.
A single workbook can have multiple sheets.
Excel files use the .xlsx extension.

Excel Formulas

Formulas perform calculations.
Examples:
=C19 + D19
=C19 * D20

Excel Functions
---------------------

Excel includes more than 168 functions.

Aggregate Functions: SUM, AVERAGE, MIN, MAX, COUNT, COUNTA
Example:
=SUM(C14:E14)

Difference between AVERAGE and AVERAGEA:

AVERAGE ignores text.
AVERAGEA treats text as 0.
