# Power BI Learning — Day 2: Visualizations

## 📌 Overview
Day 2 focused on creating and formatting visualizations in Microsoft Power BI using the Sample Superstore dataset. The session also included practical work related to connecting Power BI to MySQL and loading data from different sources.

## 📚 Topics Covered

### 1. Power BI Visualizations
Visualizations present data visually so patterns and trends are easier to understand. They are the building blocks of a Business Intelligence report.

Visual types covered:
- Bar Chart
- Column Chart
- Stacked Column Chart
- Pie Chart
- Donut Chart
- Map
- Filled Map
- Table
- Matrix
- Line Chart
- Dual Line Chart
- Line and Column Chart
- Cards: Number, Text, and Date
- Slicers: Text, Number, and Date

### 2. Creating Visuals with Sample Superstore
- Used the `Sample - Superstore` dataset.
- Loaded the `Orders` sheet into Power BI.
- Practiced creating different charts, tables, cards, and slicers using the available fields.

### 3. Formatting Visuals
Used the **Format pane** to adjust the appearance of visuals. Options covered include:
- Titles, text size, font, alignment, and color
- Background color
- X-axis and Y-axis settings
- Legend settings
- Data labels
- Borders and shadows

Formatting can vary by visual type. For example, maps include location and color-saturation settings, while tables and matrices provide grid and header formatting.

### 4. MySQL Connectivity
The session notes covered connecting Power BI to a MySQL database:
- Install the MySQL Connector (noted in the material as version 8.0.30).
- Install the MySQL ODBC Driver (noted in the material as version 8.1.0).
- Restart the machine after installation.
- In Power BI, select the MySQL connector, provide server/database details, and select the tables to load.

*Note: Driver versions above are recorded from the provided class notes; check compatibility with your installed Power BI and MySQL versions before installing.*

## 💡 Key Takeaways
- Choose a visual that matches the question and type of data being analyzed.
- Tables and matrices display detailed values, while charts help communicate comparisons, distributions, and trends.
- Cards can highlight individual values or text/date information.
- Slicers allow report users to interactively filter data.
- Consistent titles, labels, and formatting make reports easier to read.
- Different visuals provide different formatting options.
- Power BI can connect to file-based sources and databases such as MySQL when the required connector setup is available.
