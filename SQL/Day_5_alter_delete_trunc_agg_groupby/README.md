# SQL Daily Practice

A structured collection of my **SQL learning and practice work**, covering database fundamentals, table manipulation, data modification, querying, aggregation, and analytical SQL concepts.

This repository documents my hands-on SQL practice through practical examples, exercises, and progressively more advanced queries.

## 📌 About

The purpose of this repository is to build strong SQL fundamentals through consistent hands-on practice.

Each practice session contains SQL queries covering different concepts, including:

* Database and table creation
* Data insertion and manipulation
* Table structure modification
* Record deletion
* Data updates
* Filtering and querying
* Distinct values
* Aggregate functions
* Grouping and summarization
* Relational data concepts
* Practical SQL problem solving

The queries are written and tested primarily using **MySQL**.

## 🛠️ Technologies Used

* **SQL**
* **MySQL**
* **MySQL Command Line Client**
* **Git & GitHub**

## 📚 Topics Covered

### Database & Table Operations

* `CREATE DATABASE`
* `USE`
* `CREATE TABLE`
* `DROP TABLE`
* `TRUNCATE TABLE`

### ALTER TABLE

Practice includes modifying existing table structures using:

* `ADD COLUMN`
* `DROP COLUMN`
* `MODIFY COLUMN`
* `CHANGE COLUMN`
* `RENAME COLUMN`
* `RENAME TABLE`
* Adding and removing `PRIMARY KEY`
* Adding `UNIQUE` constraints

### Data Manipulation

Hands-on practice with:

* `INSERT`
* `UPDATE`
* `DELETE`

Examples include updating individual records, modifying multiple columns in a single query, and performing conditional updates.

### Data Querying

Practice with:

* `SELECT`
* `WHERE`
* `DISTINCT`
* Conditional filtering
* Selecting and inspecting table data

### Aggregate Functions

Queries using:

* `COUNT()`
* `SUM()`
* `AVG()`
* `MIN()`
* `MAX()`

These exercises focus on converting multiple records into useful summary information.

### GROUP BY

Practice includes grouping records based on specific columns and applying aggregate functions to each group.

Examples include:

* Total runs by cricket team
* Average runs by player role
* Total wickets by team

## 💡 Learning Approach

My approach is based on **learning by writing and executing queries** rather than only studying SQL syntax.

For each topic, I try to:

1. Understand the concept
2. Write the SQL query
3. Execute it in MySQL
4. Observe the result
5. Modify the query and experiment
6. Solve practical questions using the concept

This helps build both SQL syntax knowledge and practical problem-solving ability.
