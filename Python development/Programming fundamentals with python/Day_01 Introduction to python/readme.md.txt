## 📌 Key Concepts Learned

- A **Program** is a set of instructions given to a computer to perform a specific task.
- A **Programmer** writes, tests, and maintains computer programs.
- A **Programming Language** is used to communicate with computers.
- A **Compiler** translates the entire source code into machine code before execution.
- An **Interpreter** translates and executes code line by line.
- Python is an interpreted, high-level, easy-to-learn programming language.
- Python supports multiple programming paradigms and is widely used in Data Analytics, Artificial Intelligence, Machine Learning, Web Development, Automation, and many other domains.

---

## 📊 Compiler vs Interpreter

| Compiler | Interpreter |
|-----------|-------------|
| Translates the entire program at once | Translates one line at a time |
| Faster execution after compilation | Slower execution |
| Generates an executable file | No executable file generated |
| Errors shown after compilation | Errors shown immediately line by line |
