# Python Tuples – Basics and Operations

This repository contains a Jupyter Notebook demonstrating the fundamentals of **Python Tuples**. It covers tuple creation, immutability, built-in methods, indexing, and common tuple operations with simple examples.

## 📚 Topics Covered

- Introduction to Tuples
- Characteristics of Tuples
- Immutable nature of tuples
- Creating empty and single-element tuples
- Tuple packing and unpacking
- Indexing and slicing
- Built-in functions
  - `len()`
- Tuple methods
  - `count()`
  - `index()`
- Identity (`id()`) demonstration
- Examples with different data types

## 🛠 Technologies Used

- Python 3
- Jupyter Notebook

## 🎯 Learning Outcomes

After completing this notebook, you will be able to:

- Understand what tuples are and when to use them.
- Differentiate tuples from lists.
