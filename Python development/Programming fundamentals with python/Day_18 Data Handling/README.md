# Python Exception & File Handling --- Daily Practice

This repository contains my daily Python practice focused on **Exception
Handling** and **File Handling**.

## Topics Covered

### 1. Exception Handling

-   `try`, `except`, `else`, and `finally`
-   Handling `ZeroDivisionError`
-   Handling file-related exceptions such as `FileNotFoundError`
-   Different combinations of exception-handling blocks
-   User-defined exceptions using `raise`

### 2. File Handling

-   Opening and closing files
-   File modes:
    -   `r` --- read
    -   `w` --- write
    -   `a` --- append
    -   `r+` --- read and write
    -   `w+` --- write and read
    -   `a+` --- append and read
    -   `x` --- exclusive creation
-   Binary file modes using `b`
-   Reading file contents with `read()`
-   Reading lines with `readlines()`
-   Reading a specific number of characters
-   Writing with `write()` and `writelines()`
-   Appending data to existing files
-   File properties such as name, mode, readable/writable status, and
    closed status
-   File cursor operations using `tell()` and `seek()`
-   Using `with open()` for automatic file closing

### 3. Combining Concepts

-   Exception handling with file handling
-   Using `finally` to ensure files are closed
