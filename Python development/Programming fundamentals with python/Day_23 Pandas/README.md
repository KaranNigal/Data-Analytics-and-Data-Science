# 📊 Pandas Data Analysis Practice

This repository contains my daily hands-on practice with **Pandas**, focusing on commonly used data manipulation and data cleaning techniques.

## 📌 Topics Covered

### 🔹 Exploring Data

* Viewing datasets using `head()`
* Checking unique values using `unique()`
* Counting category values using `value_counts()`
* Including or excluding missing values with `dropna`

### 🔹 Handling Missing Values

* Checking missing values using `isna().sum()` and `isnull().sum()`
* Removing rows containing missing values using `dropna()`
* Filling missing numerical values using:

  * Mean
  * Median
* Filling categorical/date values using Mode

### 🔹 Sorting Data

* Sorting DataFrames using `sort_values()`
* Sorting in ascending and descending order
* Selecting specific rows after sorting

### 🔹 Column Operations

* Renaming columns using `rename()`
* Checking column names using `columns`
* Creating new columns through feature construction

### 🔹 Applying Functions

* Using `apply()` with lambda functions
* Performing calculations using Pandas broadcasting

### 🔹 GroupBy Operations

* Grouping data based on categories
* Accessing individual groups using `get_group()`
* Calculating region-wise sales
* Calculating category-wise profit

### 🔹 Combining DataFrames

* Concatenating DataFrames using `pd.concat()`
* Understanding `ignore_index=True`

### 🔹 Merge Operations

Practiced SQL-style joins using `pd.merge()`:

* Inner Join
* Left Join
* Right Join
* Outer Join

### 🔹 Filtering Data

* Filtering rows based on specific conditions
* Filtering multiple values using `isin()`
