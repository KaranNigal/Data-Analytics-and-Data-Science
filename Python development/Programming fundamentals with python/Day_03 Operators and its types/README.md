# Day 3 – Python Operators and Their Types

This repository contains my **Day 3** hands-on practice notebook from my Data Analytics & Data Science course. The notebook focuses on understanding Python operators with simple examples and practice programs.

## 📚 Topics Covered

### 1. String Data Type
- Creating strings using single quotes (`' '`)
- Creating strings using double quotes (`" "`)
- Multi-line strings using triple quotes (`""" """`)
- Printing and checking string data types

### 2. Arithmetic Operators
- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Floor Division (`//`)
- Modulus (`%`)
- Exponent (`**`)

Examples include:
- Floor vs Normal Division
- Finding Remainders
- Power Calculations

### 3. String Operations
- String Concatenation using `+`
- String Repetition using `*`

### 4. Relational (Comparison) Operators
- Greater Than (`>`)
- Less Than (`<`)
- Greater Than or Equal (`>=`)
- Less Than or Equal (`<=`)
- Equal To (`==`)
- Not Equal To (`!=`)

### 5. Logical Operators
- `and`
- `or`
- `not`

Understanding how multiple conditions are evaluated in Python.

### 6. Assignment Operators
- `=`
- `+=`
- `-=`
- `*=`
- `/=`
- `//=`
- `%=`
- `**=`

### 7. Identity Operators
- `is`
- `is not`

Difference between identity and equality.

### 8. Membership Operators
- `in`
- `not in`

Checking whether an element exists in a string or collection.

### 9. Bitwise Operators (Introduction)
- `&`
- `|`
- `^`
- `~`
- `<<`
- `>>`

Basic examples demonstrating bit-level operations.
