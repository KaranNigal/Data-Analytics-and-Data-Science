# Day 8 — Python Conditional Statements 🐍

Day 8 focused on **conditional statements in Python** and using them to make decisions based on different conditions.

## 📚 Concepts Covered

### 1. Types of Statements

Introduced the three major types of Python statements:

* **Conditional statements** — `if`, `if-else`, `if-elif-else`
* **Iterative statements** — `for`, `while`
* **Transfer statements** — `pass`, `continue`, `break`

### 2. Conditional Statements

Practiced the syntax and usage of:

* `if`
* `if-else`
* `if-elif-else`
* Nested `if-else`
* Ternary / shorthand `if-else`

### 3. Operators Used

#### Comparison Operators

```text
==   Equal to
!=   Not equal to
>    Greater than
<    Less than
>=   Greater than or equal to
<=   Less than or equal to
```

#### Logical Operators

```text
and   → Both conditions must be True
or    → At least one condition must be True
not   → Reverses the condition
```

## 🧠 Key Learning

* How Python uses conditions to control program execution.
* How `elif` can be used to handle multiple possible conditions.
* How **nested conditions** can be used when one decision depends on another.
* How logical operators can combine multiple conditions.
* How input validation can prevent invalid values from being processed.
* The importance of `:` and proper **indentation** in conditional statements.
* Difference between `=` for assignment and `==` for comparison.

## 🛠️ Practical Application

The input-validation exercises demonstrated how conditional statements can be used in real-world situations such as:

* Validating a percentage before calculating a grade.
* Checking whether a username is entered.
* Validating an email using `@`.
* Checking password length.
* Validating gender input while determining voting eligibility.
