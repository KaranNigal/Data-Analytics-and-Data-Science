## 📚 Topics Covered

### ✅ Identifiers

* Rules for naming identifiers in Python
* Valid and invalid variable names
* Case sensitivity (`name`, `Name`, and `NAME` are different)
* Using numbers in variable names
* Why identifiers cannot start with digits
* Best practices for naming variables

### ✅ Variables

* Creating and assigning variables
* Reassigning values
* Multiple variable declarations
* Understanding how Python stores values

### ✅ Python Keywords

* Viewing reserved keywords using the `keyword` module
* Why keywords cannot be used as variable names
* Understanding syntax errors caused by reserved words

### ✅ Built-in Functions

* Importance of built-in functions
* What happens when a built-in function (like `print`) is overwritten
* Restoring built-in functions using `del`

### ✅ Fundamental Data Types

* Integer (`int`)
* Float (`float`)
* String (`str`)
* Boolean (`bool`)
* Understanding data types using the `type()` function

## 🎯 Key Learnings

* Python follows strict rules for naming identifiers.
* Variable names are case-sensitive.
* Keywords are reserved and cannot be used as identifiers.
* Avoid naming variables after built-in functions.
* Every value in Python belongs to a specific data type.
