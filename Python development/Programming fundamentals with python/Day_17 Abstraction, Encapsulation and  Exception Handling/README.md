# Python OOP Practice — 

A daily Python practice repository focused on strengthening **Object-Oriented Programming (OOP)** concepts through small, practical examples.

## 📚 Topics Covered

### 1. Abstract Classes & Interfaces

Practiced using Python's `abc` module:

* Creating abstract classes using `ABC`
* Creating abstract methods using `@abstractmethod`
* Understanding why abstract classes cannot be directly instantiated
* Implementing abstract methods in child classes
* Overriding concrete methods
* Understanding the concept of interfaces
* Practical examples:

  * Car mileage
  * Vehicle wheel count
  * Shapes with area and perimeter

### 2. Encapsulation

Explored how Python classes can control access to their data.

Covered:

* Binding data and methods inside classes
* Public variables
* Protected variables (`_variable`)
* Private variables (`__variable`)
* Name mangling
* Accessing private data through class methods

Practical examples include:

* Student marks
* Banking account balance
* Finance and HR classes

### 3. Exception Handling

Practiced handling runtime errors using:

* `try`
* `except`
* Specific exceptions
* Multiple exception types
* Exception messages using `as`
* Default exception handling

Examples covered:

* `ZeroDivisionError`
* `ValueError`
* Handling multiple exceptions
* Handling unexpected exceptions
